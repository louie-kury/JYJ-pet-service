# [feat] 회원 연결 전 반려동물 등록 기능 구현

[개발 이슈 #5](https://github.com/louie-kury/louie-kury-pet-service/issues/5)의 로컬 기록입니다. 사용자 구현 승인 후 `feat/5-create-pet`에서 구현·검증을 완료했습니다. 커밋·push·PR은 별도 요청 범위입니다.

## 목적

회원가입·로그인·사용자 기능이 없는 현재 단계에서 반려동물 정보를 먼저 등록할 수 있도록 합니다. 인증과 기존 미연결 동물의 사용자 귀속은 후속 작업으로 분리합니다.

## 작업 범위

- `POST /api/pets`로 반려동물을 등록합니다.
- 이름·종·품종·생일·성별·중성화·체중·기본 접종 여부를 검증하고 MongoDB에 저장합니다.
- 회원가입·로그인은 제외하고 `caregiverId`가 null인 미연결 동물로 저장합니다. 가짜 사용자나 본문 사용자 ID를 사용하지 않습니다.
- 종·품종 관계를 검증하고 기존 공통 응답·감사 시각·한국시간 변환을 적용합니다.
- PRD `PET-01`의 등록 기능만 대상으로 하며 목록·상세 조회·수정·삭제는 제외합니다.
- 관련 자료는 공통 문서 `docs/erd.md`, `docs/api/pet.md`, `docs/api/README.md`, `docs/api/media.md`를 참고합니다.
- 입력·중복 정책은 `docs/plans/pet-registration.md` 기준으로 구현합니다. 선택 키 재사용은 기존 결과 노출 없이 409로 처리하고, 프로필 미디어 non-null은 연동 전 저장 없이 503으로 거부합니다.

## 완료 기준

- [x] 인증 없이 유효한 기본정보를 보내면 201과 등록 결과를 반환하고 소유자는 null로 저장합니다.
- [x] 잘못된 입력·종/품종 관계·사용자 ID 주입을 거부합니다.
- [x] 저장·기준 데이터 장애를 정상 등록으로 응답하지 않습니다.
- [x] 중복 요청과 날짜·체중·감사 시각의 저장/응답 매핑을 검증합니다.
- [x] 테스트·빌드·독립 리뷰 결과를 기록하고 실제 DB 검증과 대체 검증을 구분합니다.
